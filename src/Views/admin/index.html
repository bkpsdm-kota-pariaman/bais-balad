Import Data Absen
Petunjuk Singkat:
  1. Unduh file template CSV agar format kolomnya sudah sesuai sistem.
  2. Isi data absensi pegawai di file CSV tersebut.
  3. Simpan file dalam format .csv, lalu upload ke form import ini.
  4. Periksa preview data, lalu centang baris yang ingin diproses.
Isi Kolom CSV yang Wajib Disiapkan:
  • waktu: tanggal dan jam absensi, format YYYY-MM-DD HH:MM:SS. Contoh: 2026-08-17 07:30:00
  • nip: NIP pegawai. Contoh: 198001012010011001
  • nama_pegawai: nama lengkap pegawai. Contoh: Budi Santoso
  • jabatan: nama jabatan pegawai. Contoh: Staf Analis
  • opd: nama OPD atau instansi. Contoh: Dinas Komunikasi dan Informatika
  • lokasi: nama lokasi absensi. Contoh: Kantor Walikota
  • lat dan lng: koordinat lokasi absensi. Contoh: -0.6276 dan 100.1209
  • nama_file_foto: nama file foto atau link Google Drive bukti absensi. Contoh: foto_budi.jpg atau https://drive.google.com/file/d/xxxx/view
